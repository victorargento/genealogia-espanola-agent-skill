# Genealogía española

Usa la skill `skills/investigacion-genealogica-es` para investigar, revisar o
exportar genealogía. Conserva la distinción entre hechos documentados,
testimonios e hipótesis. No identifiques homónimos solo por el nombre.

Antes de publicar datos, aplica `docs/PUBLIC_TREE_POLICY.md`. El JSON es la
fuente de verdad y el GEDCOM es una exportación generada.
